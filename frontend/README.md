# Tutorías - APP-01

Frontend correspondiente únicamente a la tarea APP-01: inicio de sesión y registro.

## Tecnologías

- React
- Vite
- React Router DOM
- Axios (reservado para la integración con el backend)

## Ejecutar

```bash
npm install
npm run dev
```

## Rutas

- `/login`
- `/registro`

La interfaz utiliza únicamente CSS y React, sin librerías visuales externas. La conexión con el backend se realizará cuando estén definidos y disponibles los endpoints correspondientes.
